# Contributing

CLI and shared-core contributions are licensed under MIT. Only submit work
you have the right to contribute, and preserve third-party notices where needed.

Shared code has one source of truth in
[DataLayer-Studio](https://github.com/leeeboo/DataLayer-Studio). Submit a focused
patch there for the paths covered by `LICENSE-CLI.md`; this repository receives
allowlisted snapshots. Reports and proposed patches here are welcome, but are
integrated upstream before the next synchronization to prevent divergence.

Run `swift test` and build the release `overlay` product. Use synthetic test
data; never attach personal activities, videos, GPS traces, credentials, or
private project paths to public reports.
