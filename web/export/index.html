Encoding works independently of browser HEVC playback. Some browsers, including Firefox, show HEVC without transparency; use an editor that supports HEVC Alpha to check the downloaded file.

Bitrate is an encoding target, not a guaranteed file size. Software encoding can be slower than real time. The prototype keeps only one raw frame and up to 128 MiB of compressed video.

This prototype uses weather in the activity or template; it does not read the editor's Weather Key or cache.
